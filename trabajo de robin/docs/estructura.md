# Estructura del proyecto

- `src/main.py`: inicia la aplicación y gestiona el menú de consola.
- `src/models/tarea.py`: define los datos de una tarea.
- `src/services/tareas.py`: contiene las operaciones y guarda los datos JSON.
- `config/settings.py`: reúne rutas y valores de configuración.
- `data/`: almacena datos locales generados al usar la aplicación.
- `pyproject.toml`: identifica el proyecto y configura su empaquetado.
- `.gitignore`: evita subir archivos temporales y datos locales.
